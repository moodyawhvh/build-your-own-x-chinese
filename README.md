## 📖 项目简介

build-your-own-x 是 GitHub 上最出圈的编程自学资源合集之一,核心理念是:与其只会用轮子,不如亲手把轮子造一遍——通过从零实现数据库、操作系统、编程语言、Docker、Git、神经网络等经典技术,真正吃透它们的底层原理。仓库按技术方向分门别类,收录了数百篇优质的分步式英文教程,覆盖近 30 个大类。无论你是想补齐计算机基础的在校生、准备面试的工程师,还是单纯好奇"它到底是怎么实现的"的开发者,都能在这里找到值得动手的项目。

## 🚀 快速开始

1. 打开 [README.zh-CN.md](README.zh-CN.md),浏览「目录」,挑一个感兴趣的技术方向(比如数据库、操作系统或编程语言)。
2. 进入对应章节,选一篇教程。教程均为英文原链,语言不通可配合浏览器翻译食用。
3. 按教程步骤,用你熟悉的编程语言从零实现该技术,建议边写边做笔记。
4. 卡住时回到原项目 [Issues](https://github.com/codecrafters-io/build-your-own-x/issues) 区或教程仓库找线索。
5. 完成后复盘:对比自己的实现与真实系统的差距,总结设计上的取舍。
6. 想系统进阶?推荐按「编程语言 → 操作系统 → 数据库 → 网络协议栈」的顺序逐个挑战。
